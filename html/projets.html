Infrastructure IRIS - 802.1X

Projet de formation · 60 jours · IRIS – École Supérieure d’Informatique

Besoin

L’école avait besoin d’un réseau segmenté et sécurisé, isolant le trafic élèves, enseignants et administration, avec un contrôle d’accès Wi-Fi basé sur certificats.

Solution technique

Configuration de switches Cisco avec VLANs et routage inter-VLAN pour la segmentation ; mise en place d’un serveur NPS RADIUS couplé à l’Active Directory pour l’authentification 802.1X ; déploiement d’un VPN WireGuard ; services DNS/DHCP sur Windows Server ; sauvegardes régulières des configurations (startup-config).

Technologies

Cisco IOSVLAN / Inter-VLANNPS RADIUS802.1XActive DirectoryWireGuardDNS / DHCP

Résultats

Réseau segmenté fonctionnel sur matériel Cisco physique, contrôle d’accès Wi-Fi 802.1X opérationnel, documentation complète des procédures, et première expérience concrète sur du matériel Cisco réel.

PRA / PCA

Projet de formation · 8 jours intensifs

Besoin

Face à la montée des menaces ransomware, il fallait garantir la continuité d’activité avec une stratégie de sauvegarde immuable, un RPO < 1 h et un RTO < 30 s.

Solution technique

Sauvegardes chiffrées AES-256 immuables toutes les heures avec BorgBackup/Borgmatic ; réplication synchrone DRBD (RPO=0) couplée à Keepalived/VRRP pour un basculement automatique (RTO < 30 s) ; supervision Prometheus/Grafana ; orchestration Docker Compose sur 3 VMs provisionnées avec Vagrant.

Technologies

BorgBackupDRBDKeepalived / VRRPPrometheusGrafanaDocker ComposeVagrantOpenLDAP

Résultats

PRA validé avec restauration complète testée, bascule PCA automatique validée en moins de 30 secondes, sauvegardes résistantes aux ransomwares, et tableaux de bord de supervision en temps réel.

GitHub Documentation

Migration OneDrive - 5 To

Groupe Ragni · Nov. 2025 – Jan. 2026

Besoin

Les serveurs de fichiers locaux du Groupe Ragni étaient saturés (environ 5 To) et ne permettaient pas d’accès mobile aux données ; décision de migrer vers OneDrive / Microsoft 365.

Solution technique

Transfert des données avec le SharePoint Migration Tool (SPMT), organisé en sprints avec déploiement progressif par groupes d’utilisateurs ; automatisation du provisionnement et de la validation post-migration via PowerShell et Microsoft Graph API.

Technologies

OneDriveMicrosoft 365SPMTPowerShellGraph APIJira

Résultats

Environ 5 To libérés sur les serveurs locaux, accès mobile aux données pour toute l’entreprise, méthodologie de migration réutilisable documentée, et charge de maintenance de l’infrastructure locale réduite.

Portail listes de diffusion

Groupe Ragni · Fév. 2026 · 2 semaines

Besoin

Les chefs d’équipe ne pouvaient ni consulter ni modifier les membres des listes de diffusion Microsoft 365 ; chaque changement nécessitait un ticket support, créant des goulots d’étranglement.

Solution technique

Développement d’une interface web (HTML/CSS/JS) connectée à Microsoft 365 via PowerShell et des tâches planifiées, hébergée sur IIS en production ; déploiement automatisé par GPO Active Directory avec intégration contextuelle dans Outlook.

Technologies

HTML/CSS/JSMicrosoft 365PowerShellIISGPOActive DirectoryTâches planifiées

Résultats

Autonomie donnée aux chefs d’équipe pour gérer leurs listes, réduction significative des tickets de support niveau 1, déploiement GPO sans intervention manuelle, et adoption immédiate sans formation.
